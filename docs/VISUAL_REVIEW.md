# 视觉评审记录（Vision Review）

> 记录人：agent（视觉模型逐格判读）　日期：2026-09-14
> 目的：给"画质是否更好"补一层**定性证据**。定量判据（固定协议 val / KID / CLIP 一致性 / 盲测裁判）
> 各自有盲区，视觉判读能抓住"指标看不出来的东西"（构图合理性、伪影、文字是否被臆造等）。
> 局限写在文末：这是**单观察者、小样本**的定性结论，不能替代统计判据。

## 1. LoRA 部署形态：V4 vs V5（`research/compare_final/compare_sheet.png`）

版面：左列 = V4（部署基线），右列 = V5；6 条 prompt × 2 个 seed = 12 对，512px / 24 步。

| 场景 | 我的判读 |
|---|---|
| 日出山谷 + 雾 | 近乎一致。V5 山体更暖更饱和；V4 雾层衔接更柔 |
| 云海落日 | 一致。V5 云色更艳；V4 中间调层次略多 |
| 雪峰湖泊倒影 | V5 雪面更"脆"；V4 倒影更干净 |
| 雪岭 + 云带 | V4 云带细节稍多；V5 天空更平滑 |
| 极光（紫/绿）×2 | V5 极光更亮更艳、略偏"海报感"；V4 色彩过渡更细 |
| 瀑布 + 绿松石水潭 ×2 | 几乎相同。V5 水色更青；V4 苔藓纹理稍好 |
| 沙丘肌理 | V5 纹路更"图形化"；V4 明暗变化更自然 |
| 秋叶红树 / 小径 ×2 | V5 红色更饱和（略"烫"）；V4 叶色层次更多 |

**结论**：两者**无法可靠区分**。差异是一个很小的风格位移 —— V5 整体饱和度/对比度更高。
这与定量结果一致：饱和度 0.4600（V5）vs 0.4008（V4），锐度 656.5 vs 683.5，CLIP 0.2713 vs 0.2718。
**视觉上不支持"V5 画质更好"**，只能说"略有风格差异"。

## 2. 超分权重：bicubic / RealESRGAN / UltraSharp / Ours（`research/sr_probe_final/sr_compare_sheet.png`）

版面：列 = HR 参考、bicubic、RealESRGAN、UltraSharp、Ours-EMA、Ours-final；8 行测试裁剪（HR 512 → LR 128，×4）。

| 模型 | 我的判读 |
|---|---|
| bicubic | 明显糊：边缘发软、叶簇与水面纹理被抹平（这正是"插值不是重建"） |
| RealESRGAN | 边缘立起来，但整体偏"涂抹/塑料感"，细节偏平滑 |
| UltraSharp | **硬边最锐**：屋顶瓦片、花瓣边缘、水面泡沫的微观纹理最清楚；文字最实 |
| **Ours-EMA（自训）** | 介于 RealESRGAN 与 UltraSharp 之间：边缘干净、纹理可信、伪影少；屋顶一排比 UltraSharp 略软 |
| Ours-final（自训） | 微对比最强、最"脆"：花瓣与瀑布纹理更硬；水面出现略强的"脆感"，与实测 PSNR 更低（22.17 vs EMA 22.28）、细节量更高（8.69× vs 6.53×）一致 |

**一个值得注意的正面信号**：最后一行的 **文字（"LONDON-PARIS 1900"）在所有模型里都保持了正确字形，没有被臆造**。
GAN 超分最典型的失败模式就是把纹理幻觉成假字/假结构；我们的权重没有出现这种情况。

**结论**：自训权重**与两个商用权重同档**，风格上更接近 RealESRGAN 的"稳"、不及 UltraSharp 的"极致锐"；
它在**本地风景分布**上微调，因此已作为三个入口的默认超分模型（见 `docs/TRAINING.md` §8.1）。

## 3. 局限（必须一起读）

1. **单观察者**：判读来自一个视觉模型，不是多人评审；不同观察者的偏好会漂移。
2. **小样本**：V4/V5 只有 12 对、超分只有 8 组裁剪，且都是同一批测试图。
3. **无盲测**：本节是**非盲**判读（我知道左右分别是哪个模型）；正式的盲测由
   `tools/vlm_judge.py` 提供（随机左右交换 + Wilson 区间），结论以那份为准。
4. 定性判读适合**发现指标盲区**（伪影、臆造文字、构图崩坏），不适合判定 0.3% 量级的差异。
