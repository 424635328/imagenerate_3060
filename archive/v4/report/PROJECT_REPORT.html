LANDSCAPE·ART

Evolution

架构与训练演进

从“能用”到“高质量、鲁棒、去重”，在 6GB 显存与过拟合之间做工程权衡。

V1

基座 SD1.5 · LoRA r16

预计算 latent，fp16+检查点，512 训 3000 步，建立基线。

V2

RealisticVision · BLIP · r32

换摄影向基座；BLIP 生成 1664 张自然标题；rank 升 32，画质跃升。

V3

潜空间强增强 + 验证选优

随机翻转/缩放/平移推迟过拟合；每 200 步验证并自动存最优 checkpoint。

V3-640

640 高清微调

从 V3 权重 init，640 低 LR 900 步微调，提升原生高清。

V4

源增强 + EMA + CLIP 微调

1024 源图 × 3 随机裁剪（4560 latent）；rank 64、caption 丢弃、EMA、CLIP 低 LR 微调 → val 0.1188。

V4-640

640 高清微调 + 上线

从 V4 best init 640 微调（val 0.1262）；已作为线上默认权重。

V4 · Latest

V4：把过拟合曲线推后，再上一层画质

在 6GB/SD1.5 的硬约束下，V4 不再靠“堆步数”，而是从数据（源增强）、正则（EMA + caption 丢弃）、文本侧（CLIP 微调）三处同时下手。

1 · 源增强

1024 重提取 + 3 随机裁剪

从 zip 按 1024 重提取并复用 BLIP 标题；每图生成 3 个随机缩放/取景/翻转裁剪 → 训练 latent 1,520 → 4,560，有效数据 ×3。

2 · 容量与正则

rank 64 + dropout 0.1 + weight decay

更大容量配合更强正则；caption 随机丢弃 0.05 提升 prompt 跟随与泛化。

3 · EMA

权重滑动平均 0.9995

每步更新 EMA，验证与导出都用 EMA 权重；训练曲线更平滑、成品更干净。

4 · 文本侧

CLIP 文本编码低 LR 微调

lr 1e-5 微调 text encoder，显著改善风格/概念对齐；训练与验证均改为在线编码 caption。

结果：最优验证损失 0.1188（step 4800，EMA）；V4-640 微调后 0.1262（step 400）。 同 prompt 同 seed 的 V3↔V4 对比见 outputs/v3_vs_v4.png，V4 样张见 outputs/gallery_v4/ 与 outputs/gallery_v4_640/。
速度真相：500 步 ≈ 200 s 且更易过饱和；标准 24 步 ≈ 6 s 且质量与 40 步基本一致（≈33× 提速）。 另有 LCM 极速模式（4–6 步 ≈ 3–4 s）。实测对比：outputs/bench/bench_compare.png。
Training

训练损失与验证曲线

曲线显示验证损失在 step 1000 最优（0.1176） 后上升（过拟合），故发布最优 checkpoint 而非训到底。

工程取舍：rank32 在 1,520 张图上约 1000 步起过拟合，采用“长调度+验证早停+自动存最优”得到泛化最好的权重。

Usage

使用方式

# 风格 prompt 生成
python inference.py --base SG161222/Realistic_Vision_V6.0_B1_noVAE \
  --lora "$ROOT/models/v3_640/adapter_best" \
  --prompt "a misty alpine lake at dawn" --width 768 --height 768 --steps 45 --scheduler dpmpp2m_karras

# 空提示 -> 随机
python inference.py --base SG161222/Realistic_Vision_V6.0_B1_noVAE \
  --lora "$ROOT/models/v3_640/adapter_best" --width 768 --height 768

# 交互式 App
双击  启动Gradio.bat   或   python app.py   →  http://127.0.0.1:7860

# 4x 超分
python upscale.py in.png out.png
